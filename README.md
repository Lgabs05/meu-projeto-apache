# Projeto Apache com Docker

## 📌 Descrição
Projeto simples utilizando Docker Compose para subir um servidor Apache com uma aplicação web (Hello World).

## 🚀 Tecnologias utilizadas
- Docker
- Docker Compose
- Apache (httpd)

## ▶️ Como executar

1. Clone o repositório:git clone https://github.com/Lgabs05/meu-projeto-apache.git
2. Acesse a pasta: cd meu-projeto-apache
3. Execute: docker compose up -d
4. Acesse no navegador:http://localhost:8080
5.
